            The verification loop
            
From “looks done” to
evidence it works.

          

          
Each tool does one job well, and each result gives the next step enough context to act.

        

        

          

            01
            
⌁

            scan_url
            
Find what broke

            
Run nine checks from one page load: console, links, accessibility, SEO, headers, privacy, weight, and vitals.

          

          

            02
            
◎

            inspect_page
            
See what the agent can use

            
Return page structure, accessible controls, and ranked Playwright locator candidates without guesswork.

          

          

            03
            
↳

            generate_playwright_repro
            
Preserve the failure

            
Turn a finding into a deterministic, reviewable Playwright test contained inside the workspace.

          

          

            04
            
▶

            run_playwright_test
            
Verify the claim

            
Execute one focused test behind an explicit approval gate and return structured, auditable evidence.
